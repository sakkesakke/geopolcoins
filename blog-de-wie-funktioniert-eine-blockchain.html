Wie funktioniert eine Blockchain? Bau eine winzige im Browser

6 November 2026 · 1 Min. Lesezeit · Tool: Mini-Chain

Auch auf: English Nederlands Français Español Português Türkçe Bahasa Indonesia

Kurze Antwort

Eine Blockchain ist eine Liste von Blöcken, in der jeder Block den Fingerabdruck (Hash) des vorherigen Blocks speichert. Ändere einen Buchstaben in einem alten Block, und sein Fingerabdruck ändert sich, wodurch jeder spätere Block bricht. Darum ist Geschichte so schwer umzuschreiben.

Schritt 1: der Fingerabdruck

Eine Hash-Funktion wie SHA-256 verwandelt jeden Text in einen Code fester Länge. Ändere einen Buchstaben, und der Code ändert sich komplett. Vom Code kommst du nicht zurück zum Text.

Schritt 2: Blöcke, verbunden durch Fingerabdrücke

Jeder Block enthält Daten, eine Zahl namens Nonce und den Hash des vorherigen Blocks. Weil jeder Block auf den davor zeigt, bilden die Blöcke eine Kette.

Schritt 3: Mining

Bei Proof-of-Work-Ketten wie Bitcoin zählt ein Block nur, wenn sein Hash mit einer bestimmten Anzahl Nullen beginnt. Miner probieren eine Nonce nach der anderen, bis sie eine finden. Das kostet Arbeit, und es für viele Blöcke zu wiederholen, kostet noch mehr.

Schritt 4: Versuch zu schummeln

Bearbeite einen alten Block, und du siehst, wie sich sein Hash ändert und jeder spätere Block ungültig wird. Um das zu reparieren, müsstest du alle neu minen, schneller als alle anderen. In einem großen Netzwerk ist das praktisch unmöglich.

Solana nutzt ein anderes System (Proof of Stake mit Proof of History), aber die Idee der durch Hashes verbundenen Blöcke ist dieselbe.

Öffne die Mini-Chain, tippe irgendwas, mine einen Block, ändere dann einen Buchstaben und sieh zu, wie die Kette bricht. Nichts wird gesendet, es sind keine echten Coins im Spiel.
