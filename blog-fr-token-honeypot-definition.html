Qu'est-ce qu'un token honeypot, et comment le repérer ?

6 novembre 2026 · 1 min de lecture · Outil: Token Checkup

Aussi en: English Nederlands Español Português Deutsch Türkçe Bahasa Indonesia

Réponse rapide

Un token honeypot est conçu pour que l'achat fonctionne, mais que la vente échoue ou soit taxée presque à zéro. Le signe public le plus clair : beaucoup d'achats et aucune vente. Vérifiez avant d'acheter ; après, il est trop tard.

Comment fonctionne un honeypot

L'astuce se trouve dans les règles du token ou dans la configuration du pool. Le graphique ne fait que monter, parce que personne ne peut vendre. Ce graphique qui monte, c'est l'appât. Les gens achètent, essaient de vendre, et découvrent qu'ils ne peuvent pas.

Les signes que vous pouvez voir

  • Des achats mais aucune vente sur les dernières 24 heures, par exemple 58 achats et 0 vente.
  • Une alerte d'une source de données : GeckoTerminal signale certains tokens comme honeypot possible.
  • Le droit freeze est encore actif : le créateur peut geler votre compte pour que vous ne puissiez plus bouger vos tokens.
  • Le prix ne fait que monter en ligne parfaite, souvent sur un pool tout neuf avec peu de liquidité.

Ce que vous pouvez faire

  1. Collez l'adresse dans le Token Checkup gratuit et lisez chaque alerte.
  2. Regardez les transactions récentes dans un explorateur : voyez-vous de vraies ventes par différents wallets ?
  3. Si vous voulez quand même essayer, n'utilisez jamais de l'argent que vous ne pouvez pas perdre.

Aucune vérification publique n'attrape tous les honeypots. Éducatif seulement, pas un conseil financier.

Questions

Puis-je récupérer mon argent d'un honeypot ?

Généralement non. Les transactions sur la blockchain ne peuvent pas être annulées. La prévention est la seule vraie protection.

« Pas d'alerte honeypot » veut-il dire que c'est sûr ?

Non. Cela veut seulement dire que la source de données n'a vu aucun signe que la vente est bloquée.
