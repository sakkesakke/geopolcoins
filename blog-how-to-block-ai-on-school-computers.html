How to block ChatGPT and AI tools on school computers

10 November 2026 · 1 min read · Tool: Human Override

Also in: Nederlands Français

Quick answer

For a few computers, install a blocker such as Human Override. For the whole school, let IT push a browser URL blocklist (Chrome or Edge policy) and block AI domains on the school DNS or firewall. The free Human Override Pro pack has ready-made files for all of these.

Exam week, and half the class has a chatbot open in another tab. Schools do not need to ban AI forever, but they do need a switch they control: off during tests, on when a teacher wants to use it.

Option 1: per computer (a few minutes)

Install Human Override on each computer. The Windows and Mac versions block AI for every browser and app; the browser extension adds a PIN lock. Good for a single classroom or a library.

Option 2: browser policy (IT, whole school)

Chrome and Edge accept a URLBlocklist policy that IT can push through Google Admin, Intune or Group Policy. Firefox has a similar WebsiteFilter policy. The Pro pack contains both, filled with the current AI list.

Option 3: the network (IT, every device)

  • DNS: files for BIND (RPZ), Unbound, dnsmasq and Windows DNS Server policies, so AI addresses return “does not exist”.
  • Firewall: a plain domain list for firewalls that accept external lists.
  • Proxy: a Squid ACL file.
  • Network blocking also covers student phones on the school Wi-Fi.

Students on mobile data or a VPN are outside the school network. Combine network rules with clear rules in the classroom.

Questions

Does this block Google search?

No. Normal search keeps working. Google's separate AI Mode is blocked by the browser extension.

Can teachers still use AI?

Yes. Allow specific tools, or switch blocking off on teacher accounts or devices.

How often is the list updated?

The public list updates as new AI services appear; the apps and extension download it daily.
