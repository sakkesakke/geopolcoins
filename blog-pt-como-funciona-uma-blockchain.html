Como funciona uma blockchain? Monte uma minúscula no navegador

6 novembro 2026 · 1 min de leitura · Ferramenta: Mini-Chain

Também em: English Nederlands Français Español Deutsch Türkçe Bahasa Indonesia

Resposta rápida

Uma blockchain é uma lista de blocos em que cada bloco guarda a impressão digital (hash) do bloco anterior. Mude uma letra num bloco antigo e a impressão muda, o que quebra todos os blocos seguintes. Por isso é tão difícil reescrever a história.

Passo 1: a impressão digital

Uma função hash como a SHA-256 transforma qualquer texto num código de tamanho fixo. Mude uma letra e o código muda por completo. Não dá para voltar do código para o texto.

Passo 2: blocos ligados por impressões

Cada bloco guarda alguns dados, um número chamado nonce e o hash do bloco anterior. Como cada bloco aponta para o anterior, os blocos formam uma corrente.

Passo 3: minerar

Em redes de prova de trabalho como o Bitcoin, um bloco só vale se o hash começar com certa quantidade de zeros. Os mineradores testam um nonce atrás do outro até achar um. Isso dá trabalho, e refazer para muitos blocos dá ainda mais.

Passo 4: tente trapacear

Edite um bloco antigo e você verá o hash mudar e todos os blocos seguintes ficarem inválidos. Para consertar, teria que minerar todos de novo, mais rápido que todo mundo. Numa rede grande isso é praticamente impossível.

A Solana usa outro sistema (prova de participação com prova de histórico), mas a ideia de blocos ligados por hashes é a mesma.

Abra a Mini-Chain, digite qualquer coisa, minere um bloco, depois troque uma letra e veja a corrente quebrar. Nada é enviado e não há moedas de verdade.
