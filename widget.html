Free token checker widget

Give your readers a way to check any Solana token for public red flags, right on your own site. One line of code, no API key, no cookies. Great for crypto blogs, community pages and project FAQs.

Add it in one minute

Option 1, script (auto height). Paste this where the box should appear:

<div class="maiga-checkup" data-theme="dark"></div>
<script src="https://geopolcoins.xyz/widget.js" async></script>

Option 2, plain iframe (for site builders that block scripts):

<iframe src="https://geopolcoins.xyz/embed.html?theme=dark" title="Token Checkup" width="100%" height="330" style="max-width:420px;border:0;border-radius:14px" loading="lazy"></iframe>

Options

  • data-theme="light" for light websites.
  • data-mint="TOKEN_ADDRESS" to check one token straight away, for example your own project.
  • data-fixed="1" together with data-mint hides the address box.

What it checks

  • Liquidity and pool age
  • Mint and freeze authority
  • Top 10 holders and the creator wallet
  • Honeypot signals and buys without sells
  • Volume against liquidity and big 24-hour jumps

Questions

Is the token checker widget free?

Yes. It is free for any website, blog or community page. Please keep the small Powered by geopolcoins.xyz link visible.

Does the widget track my visitors?

No cookies and no ad trackers. The widget reads public token data from GeckoTerminal in the visitor's browser and counts one anonymous view (page name and referring site only).

Can the widget say a token is safe?

No. It shows public red flags. A token without flags can still fail or be a scam. It is a checklist, not financial advice.
